对应需求：[`docs/requirements/Lastab-需求说明-v0.5.md`](../docs/requirements/Lastab-需求说明-v0.5.md)。设计版本 v0.6（经过两轮评审修订）。

在线画布：<https://claude.ai/artifact/2ev4fABBLpxom8xdxAb8SN>（私有，需在页面的 Share 菜单中共享后他人才能打开）。

## 目录

| 路径 | 内容 |
| --- | --- |
| `canvas/canvas.json` | 画布索引：4 个页面、38 张画板的位置、标题与便签 |
| `canvas/<屏幕>.dc.html` | 7 个主屏幕的源文件，每个文件包含全部状态、语言、主题与平台 |
| `canvas/<屏幕><变体>.dc.html` | 只引用主屏幕并传入参数的变体（状态、深色英文、Windows） |
| `tokens.json` | 颜色（浅色 / 深色）、强调色规则、圆角、间距、字体、动效时长 |
| `brand/` | 标志：SVG 母版（横版、竖版、图形、字标、应用图标）与使用说明 |

`.dc.html` 是 Design 画布格式，依赖画布运行时（`./support.js`），不能直接用浏览器打开。查看请用上面的画布链接；修改后把 `canvas/` 下的文件重新发布到同一画布即可。

### 主屏幕的参数（画布 Tweaks）

| 参数 | 取值 | 作用 |
| --- | --- | --- |
| `theme` | `light` / `dark` | 外观 |
| `locale` | `zh` / `en` | 界面语言（片段内容不翻译） |
| `platform` | `mac` / `win` | 窗口按钮与快捷键写法 |
| `accent` | 颜色 | 强调色；按钮文字颜色按亮度自动选择 |
| `view` | 依屏幕而定 | 状态，如编辑器的 `rest` / `blank` / `copied` / `recovered` |

可点的画板：切换器（先点输入框，再用 Tab / 方向键 / 输入过滤）、待办、版本历史（恢复与撤销）、设置（外观、语言、平台即时切换）、Agent 访问。

## 设计约定

- **颜色只用 `tokens.json` 里的变量**，浅色与深色同名；不在组件里写死颜色。
- **圆角**：内层 = 外层 − 内边距，最小 4px；窗口与面板 12，控件 8，小元素 4。间距在 4px 网格上。
- **反馈**：
  - 可撤销的操作立即执行，并给「撤销」轻提示（≥ 5 秒，带倒计时），如清除已完成、删除待办项、恢复版本、粘贴拆分。
  - 不可撤销的永久删除，用锚定在按钮上的确认气泡，写明删除对象与后果。
  - 复制全部不弹轻提示，按钮原地确认，并以 polite 方式播报。
  - 需要用户处理的失败（如留存失败、安装失败）留在出错的位置，带重试，不用会消失的轻提示。
- **轻提示**：顶部居中、标题栏下 12px，一次一条，悬停或聚焦时暂停计时，不抢焦点。
- **多语言**：
  - 界面文字放进语言资源文件，片段与待办内容不翻译。
  - 中英文之间的空隙交给 `text-autospace`。不支持它的 WebView（如 macOS 15.4 以前的 WKWebView）在渲染界面文字时补细空格，资源文件里不手打空格。
  - 计数与时间用等宽数字。
- **无障碍**：
  - 编辑器 tab 用 tablist / tab；切换器与搜索用 combobox + listbox，键盘上下选择。
  - 只在悬停时出现的控件，在键盘聚焦时也出现。
  - 文字对比度满足 WCAG AA。
- **动效**：时长取桌面值；「减少动态效果」时只保留状态变化与约 150ms 淡入淡出。细节见画布「状态」页的蓝色便签。
